# Лабораторные работы по SDR

Здесь собран код лабораторных работ с **ADALM-Pluto**.

## Лабораторная №1 — Знакомство с ADALM-Pluto

В первой работе нужно было разобраться, как устроен PlutoSDR и как управлять им из программы.

Использовали **SoapySDR**: настраивали частоту, частоту дискретизации и усиление, создавали потоки на передачу (TX) и приём (RX).

Работали с **IQ-сэмплами** — это отсчёты сигнала, состоящие из двух компонент: I и Q.

Отдельно разбирались с **timestamp** — временными метками, которые позволяют отслеживать время приёма данных и задавать момент передачи.

Принятые сэмплы записывали в `.pcm`, а затем строили графики на Python, чтобы посмотреть, что получилось.

---

## Лабораторная №2 — Связь между двумя SDR

Во второй работе задача была уже практическая: настроить два ADALM-Pluto, установить между ними связь и передать файл.

Одно устройство использовали для передачи, второе — для приёма.

Сначала проверили подключение обоих SDR, затем настроили частоты и остальные параметры. После этого запустили обмен данными и проверили, что сигнал принимается на другой стороне.

В итоге удалось настроить связь между двумя SDR и выполнить передачу файла.

Выложенный код в основном показывает работу с потоками IQ-сэмплов и сохранение принятых данных в `.pcm`.

## Что использовалось

- **ADALM-Pluto** — два SDR-устройства.
- **C/C++** — основной код для работы с устройствами.

## Сборка и запуск

Перед запуском должны быть установлены необходимые библиотеки и подключены SDR.

### Сборка

Из папки нужной лабораторной:

```bash
mkdir -p build
cd build
cmake ..
make
```

### Запуск

Для версии программы, где передаются режим и адрес устройства, запуск выглядит так:

**Приёмник (RX):**

```bash
./build/main rx usb:<адрес_приёмника>
```

**Передатчик (TX):**

```bash
./build/main tx usb:<адрес_передатчика>
```

Адреса подключённых устройств можно посмотреть командой:

```bash
SoapySDRUtil --find
```

В других версиях программы параметры подключения могут быть заданы прямо в коде.
